# HearMe AI

AI-powered environmental sound recognition and accessibility assistant
for Deaf and hard-of-hearing people.

**Status:** In development (Phases 1-2 complete)

## Progress
- [x] Phase 1: Dataset exploration (ESC-50)
- [x] Phase 2: Audio preprocessing and MFCC features
- [X] Phase 3: Random Forest and SVM
- [ ] Phase 4: YAMNet transfer learning
- [ ] Phase 5-8: App, live detection, accessibility, deployment

> This is an assistive prototype, not a certified emergency warning system.
> It must not replace official fire alarms or safety equipment.

## Dataset
ESC-50: https://github.com/karolpiczak/ESC-50 (CC BY-NC license).
The dataset is not included in this repository.
